# 沿海台风观察

面向沿海居民的台风实况与路径信息页面。当前接入[浙江省水利厅实时台风路径系统](https://typhoon.slt.zj.gov.cn/)公开展示的数据，显示活动台风名称、编号、中心经纬度、移向、移速、中心附近最大风力、最近观测路径与来源系统标记为“中国”的预报路径。

**本站未接入区县级气象预警。** 页面上的“无法判断当地预警状态”不是“无预警”；防灾行动请以当地气象和应急部门最新通知为准。项目计划见 [PLAN.md](./PLAN.md)。

## 数据与更新时间

- GitHub Actions 在每小时的第 7、22、37、52 分钟（UTC）计划运行，间隔 15 分钟；GitHub 可能延迟或跳过计划任务。推送到 `main` 或手动运行也会触发同步。
- 抓取脚本：`scripts/fetch-zj.mjs`。读取活动台风、当年及上一年台风列表和活动台风详情，校验并生成 `data/latest.json`。抓取失败时工作流失败，不发布一份冒充新数据的快照。
- 页面读取 `data/latest.json`，打开期间每 5 分钟重新读取。同步时间超过 45 分钟、或最新台风观测超过 6 小时，页面显示过期提示。这是本站的显示阈值，不是来源系统的数据有效期承诺。
- 路径图按经纬度线性绘制，无地图底图；不表示风圈、影响范围或登陆地点。实况与预报使用不同线型，并有文字路径。预报机构名称按来源系统原字段显示。
- 每次部署只包含最新快照，不在 Git 历史中保存原始数据。来源端点为公开网页使用的 JSON 接口，但目前未找到明确的数据再发布许可或稳定接口承诺；正式长期运营需向数据方核实使用条件与接口变更通知。

## 本地查看

需要 Node.js 22 或更新版本。运行 `node scripts/fetch-zj.mjs` 获取最新快照，再用静态 HTTP 服务器打开仓库根目录，例如 `python -m http.server 8000`，访问 `http://localhost:8000/`。直接双击 `index.html` 使用 `file://` 协议时，浏览器可能阻止 JSON 读取。

运行 `node --test test/fetch-zj.test.mjs` 验证标准化、无活动台风与错误响应处理。

## 部署

仓库 Settings → Pages → Build and deployment → Source 选择 **GitHub Actions**。工作流位于 `.github/workflows/deploy-pages.yml`，从官方来源生成快照并部署到 GitHub Pages。项目站点路径为 `https://marktoluv.github.io/coastal-typhoon-alert/`。

台风中心风力与本地预警级别没有直接对应关系，本站不会自行发布或推算任何级别的预警。
