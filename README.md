# 沿海台风信息与分级预警网站

面向中国沿海居民的移动优先台风信息网站项目。当前仓库保存产品与实施计划，尚未接入实时数据，也不提供正在生效的预警。

计划书：[台风信息网站计划书](./PLAN.md)

## 目标

让居民打开网页后，能快速看清：

1. 当前台风叫什么，信息发布于何时；
2. 台风中心在哪里，正在往哪走；
3. 中心附近最大风力有多大；
4. 自己所在地区是否有气象部门发布的台风预警，以及该怎么做。

正式上线前，必须落实气象数据的合法获取与使用、地区预警的直接来源、更新与失效机制，并完成移动端和弱网场景验证。开发期间使用明确标注的演示数据。

## 项目状态

- 阶段：需求与方案
- 服务范围：中国沿海地区，首期以用户手动选择区县定位
- 详细范围、数据模型、实施步骤、验收标准：见 `PLAN.md`

## 信息使用说明

计划书中的预警等级用于解释气象部门已发布的信号。网站本身不发布、预测或自动生成官方预警。台风等级与某地预警信号是不同概念；实际防灾行动以当地气象部门及应急部门最新信息为准。
